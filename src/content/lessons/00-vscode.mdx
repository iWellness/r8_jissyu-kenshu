## 作業フォルダ以下を信頼する（1回目のみ）

VS Code for Webで作業フォルダを開いたとき、信頼を確認する画面が表示されます。自分が用意した作業フォルダであることを確認してから、信頼する操作を行います。

<Figure src={trustImage} alt="VS Code for Webで作業フォルダを信頼する確認画面" caption="作業フォルダを信頼する画面" />

<Callout type="note" title="確認">
  作業フォルダの場所と名前を確認してから進めてください。共有されたフォルダや内容が分からないフォルダは、講師に確認します。
</Callout>

## Terminalを開く

画面上部のメニューまたはターミナルのアイコンから、ターミナルを開きます。以降の章で入力するコマンドは、このターミナルで実行します。

<Figure src={terminalImage} alt="VS Code for Webでターミナルを開くメニュー" caption="ターミナルを開く" />

<Callout type="check" title="この章の完了条件">
  作業フォルダを信頼し、ターミナルに入力できる状態になれば完了です。
</Callout>
