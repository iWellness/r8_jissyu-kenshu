## Install

### 1. Installページにアクセス

[QIIME 2 AmpliconのInstallページ](https://library.qiime2.org/quickstart/amplicon) を開き、`Using conda` をクリックします。

ドキュメントページから移動する場合は、次の画面を目印にします。

<Figure src={installPageImage} alt="QIIME 2ドキュメントからインストールページへ進む画面" caption="QIIME 2のインストールページへの導線" />

### 2. condaでのインストール方法を選択

`2026.1` を選択し、`Using Conda` > `Install the base distribution’s conda environment` > `Linux / Windows WSL` の順に選びます。

<Figure src={installLinuxImage} alt="QIIME 2のLinux / Windows WSL向けcondaインストール手順" caption="Linux / Windows WSLのインストール手順" />

### 3. インストール

公式ページに表示された `conda ...` のコマンドを確認し、ターミナルで実行します。

<CommandBlock id="qiime2-create-environment" code={createEnvironment} language="bash" kind="command" context="ターミナル" title="QIIME 2 2026.1のconda環境を作成" />

途中で `Proceed ([y]/n)?` と聞かれた場合は、`y` を入力して進めます。環境作成には数分かかる場合があります。

## conda環境の有効化

condaのメリットは、`RNA-Seq` や `QIIME 2`、`Python` など、環境ごとにパッケージを管理できることです。

現在、QIIME 2環境の外にいるため、`qiime` コマンドが使えない状態です。

まず、環境名を確認します。

<CommandBlock id="qiime2-env-list" code={envList} language="bash" kind="command" context="ターミナル" title="conda環境の一覧を確認" />

<ExpectedOutput code={envOutput} caption="今回の環境一覧の例" />

`rachis-qiime2-2026.1` を確認し、次のコマンドで有効化します。

<CommandBlock id="qiime2-activate" code={activateQiime} language="bash" kind="command" context="ターミナル" title="QIIME 2環境を有効化" />

これでQIIME 2環境が有効化され、`qiime` コマンドが使えるようになります。
