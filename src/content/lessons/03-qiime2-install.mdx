## インストール

### 1. インストールページにアクセス

[QIIME 2 AmpliconのInstallページ](https://library.qiime2.org/quickstart/amplicon) を開き、`Using conda` をクリックします。

### 2. condaでのインストール方法を選択

`2026.1` を選択し、`Using Conda` > `Install the base distribution’s conda environment` > `Linux / Windows WSL` の順に選びます。

## 仮想環境とは

仮想環境は、特定のソフトウェアとそのバージョンを1つのフォルダにまとめ、ほかの環境から分けて管理する仕組みです。condaの公式ドキュメントでは、conda環境を「インストールしたパッケージの特定の組み合わせを含むディレクトリ」と説明しています。[1]

仮想環境は、作業ごとに用意する**専用の道具箱**と考えると分かりやすくなります。

- `base`環境：condaを動かすための基本の道具箱
- `qiime2-2026.1`環境：QIIME 2 2026.1と解析に必要なパッケージを入れた道具箱
- `conda activate qiime2-2026.1`：使う道具箱を`qiime2-2026.1`へ切り替える操作

ある仮想環境でパッケージを追加・更新しても、別の仮想環境には影響しません。そのため、QIIME 2が必要とするソフトウェアの組み合わせを保ちながら、ほかの解析環境と共存できます。

この図では、`root environment`（現在の`base`環境に相当）とは別に、異なるPythonとパッケージを持つ環境を複数作れることを示しています。[2] 図の出典はGeoHackWeekで、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)に基づいて掲載しています。[3]

仮想環境は、パソコンの中に別のOSを起動する仕組みではありません。OSごと分離する仮想マシンとは異なります。現在のLinux環境の中で、優先して使うコマンドとパッケージの保存場所を切り替えます。
